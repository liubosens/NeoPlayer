## 🌐 mpvEx 官网

这是 **mpvExtended** 的官方 Next.js 网站 —— 一款基于 mpv 打造的强大 Android 视频播放器。网站用于展示功能、提供下载，并作为项目的线上门户。

### 🚀 快速开始

```bash
# 开发
pnpm dev           # 启动开发服务器
pnpm dev:debug     # 启用调试

# 依赖关系图
pnpm analyze       # 分析依赖

# 构建
pnpm build         # 构建生产版本
pnpm start         # 启动生产服务器
pnpm start:prod    # 在 3000 端口启动

# 代码质量
pnpm lint          # 运行检查
pnpm lint:fix      # 自动修复问题
pnpm format        # 格式化代码
pnpm type-check    # TypeScript 类型检查

# 维护
pnpm clean         # 清理构建产物
pnpm reinstall     # 完整重装依赖

```

## 📦 项目结构

- 框架：Next.js 16.1.5 搭配 React 19.2.4
- 样式：Tailwind CSS 4.1.18 结合 Material Design
- 语言：TypeScript
- 代码检查：使用 Biome 进行格式化与检查
- 图标：Lucide React 及自定义图标


## 🎯 特性

- 现代技术栈：基于 Next.js 16、React 19 与 TypeScript 构建
- 响应式设计：Tailwind CSS 结合 Material Design 原则
- 性能优化：自动代码分割与优化
- 类型安全：全面覆盖 TypeScript，启用严格类型检查
- 代码质量：使用 Biome 统一格式化与检查
